Idea

Home's chat stays on the left (narrower); the right side becomes a task panel. Its tab bar is the task list (stage dot, needs-you count, machine icon), with a Board tab showing all cards. Fork tasks get an agent tree down the panel's left edge. Closing the panel (or ⌘\) gives Home the full width again.

Pros

  • Home and a task are visible at once: tell Home "merge T3" while reading T3
  • Never "lost": no back navigation at all
  • Agent tree shows a fork's structure at a glance

Cons

  • Two composers on screen; need a clear "to …" label and focus ring
  • Cramped below ~1200px: needs a collapse-to-drill-in fallback
  • Cards shrink to tabs; summaries only on the Board tab

home_view.rs changes

  • render_home: chat + render_home_rail → chat + new render_task_panel (tabs, agent tree, CodeView); rail cards move into the Board tab
  • New home.open_tasks: Vec<id>, home.panel: Option<(task, agent)>, split width persisted
  • open_task_card opens/raises the panel tab; pane focus only from the ⋯ menu
  • Second CodeView entity alive at once (Home + task)
