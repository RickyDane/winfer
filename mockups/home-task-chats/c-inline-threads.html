Idea

Every task lives as a collapsible thread right under the Home message that started it, like Slack replies inline. Expanded, it shows the agent's latest turns, its pending question/approval and a small reply box that talks to that agent. Fork threads get agent chips in the thread header. The rail stays as an index: clicking a card scrolls to its thread and expands it. Needs-you items are hoisted into a banner at the top.

Pros

  • Context is kept: why a task exists sits right above it
  • Several tasks can be open at once, answered in one scroll
  • Home chat never goes away

Cons

  • Long threads bloat the Home transcript; needs "show earlier" + height caps
  • Many composers; keyboard focus gets ambiguous
  • Hardest to build: nested CodeView transcripts inside a CodeView

home_view.rs changes

  • New home.expanded: HashSet<(task, agent)> instead of home.thread; tab row removed
  • Conductor transcript gets a "task thread" item kind anchored to the update_task call; renders a trimmed child CodeView (last N items + dock + mini composer)
  • open_task_card → expand + scroll-to-anchor
  • Hoisted needs-you banner from home.tasks stages
