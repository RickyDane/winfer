Idea

Clicking a card pushes the task's chat into the same chat panel Home uses. A breadcrumb Home › T2 › backend replaces the tab row; back is the breadcrumb, Esc or ⌘[. The task rail stays, so switching tasks is one click and cards show which one is open. Fork agents are a chip row under the breadcrumb.

Pros

  • Full width for the transcript, approvals, diffs
  • Smallest change: generalizes today's home.thread
  • One composer, always obvious who it talks to

Cons

  • Home chat is hidden while you're in a task (a peek strip shows new Home replies)
  • Comparing two tasks side by side isn't possible

home_view.rs changes

  • home.thread: Option<String> → Option<(task_id, agent_id)>, plus a back stack
  • open_task_card: every mode sets home.thread; no more home_focus_pane/WorkspaceSwitch
  • home_view_for resolves light panes and remote panes (remote via the peer's CodeModel proxy)
  • render_home_chat: tab row → breadcrumb + agent chips; pane/worktree go to a ⋯ menu
