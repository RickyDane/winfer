Design notes

What changed

  • Tabs grouped by workspace with a colored rail instead of text labels.
  • Real tab shape; agent-driven tabs tinted in agent color.
  • Omnibox with host emphasis + focus ring; desktop/mobile toggle inline.
  • Soft agent banner + quiet ring + ghost cursor when an agent drives the tab, with “Take over”.
  • Collapsible console drawer with error/warn counts.
  • Device picker chip with serial/API; connection chip.
  • Phone rendered in a bezel frame on a soft spotlight (Fit / 1:1 / Frame).
  • Vertical action rail: nav keys, rotate, volume, keyboard, screenshot, record.
  • Agent taps visualized as ripples.
  • Inline filtered logcat strip.
  • Workspace pills with workspace color.
  • Path breadcrumb + git branch chip.
  • Command blocks: left rail shows success/failure, duration on the right.
  • Floating find bar with match count.
  • Footer: shell, size, last exit code.
  • Multi-file tabs with type badges and modified dot.
  • Rendered / Source / Diff modes.
  • Outline sidebar for markdown.
  • @user / @agent comments rendered as threaded callouts instead of raw HTML comments.
  • Author line shows which agent wrote the file.

Shared system

  • Segmented switcher with icons, live dots, badges, ⌘1–4 hints.
  • Relaxed spacing: 48px toolbar → content → 32px status footer.
  • Same chips, icon buttons and mode toggles everywhere.
  • Warm graphite and lavender palette, subtle borders and soft elevation; coordinated light theme.
