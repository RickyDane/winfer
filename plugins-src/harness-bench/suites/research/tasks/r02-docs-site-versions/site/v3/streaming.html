Streaming (lumen 3.x)

You are reading the docs for lumen 3.x (current).

Client.stream() from 2.x is gone. Use Client.open_stream(method, url):

with client.open_stream('GET', url) as r:
    for chunk in r.iter_bytes(): ...

Headers are case-insensitive mappings.

Query parameters can be passed as a dict or a list of pairs.

Connection pooling is enabled by default and shared per client.
