Requests (lumen 3.x)

You are reading the docs for lumen 3.x (current).

Responses are read lazily; call .read() to load the whole body.

Headers are case-insensitive mappings.

The transport layer can be replaced for testing with a mock transport.

Redirects are followed up to a limit; see the client options.
