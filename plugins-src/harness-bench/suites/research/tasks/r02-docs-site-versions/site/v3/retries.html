Retries (lumen 3.x)

You are reading the docs for lumen 3.x (current).

Retries are configured with lumen.RetryPolicy(max_attempts=3, backoff=0.5). max_attempts counts the first try, so the default of 3 means up to two retries. Only idempotent methods are retried.

Query parameters can be passed as a dict or a list of pairs.

Connection pooling is enabled by default and shared per client.

The transport layer can be replaced for testing with a mock transport.
