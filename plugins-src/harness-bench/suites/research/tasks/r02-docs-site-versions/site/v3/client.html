Client (lumen 3.x)

You are reading the docs for lumen 3.x (current).

lumen.Client(base_url=None, timeout=Timeout.default(), tls_verify=True, retry=RetryPolicy(), headers=None)

  • timeout: a Timeout or a number of seconds.
  • tls_verify: set to False to disable TLS certificate verification (the 2.x name verify was removed).
  • retry: a RetryPolicy.

Use a context manager so connections are released promptly.

Cookies set by the server are stored in the client's cookie jar.
