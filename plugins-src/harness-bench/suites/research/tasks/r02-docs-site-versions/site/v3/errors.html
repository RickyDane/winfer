Errors (lumen 3.x)

You are reading the docs for lumen 3.x (current).

Responses with status 4xx or 5xx raise lumen.StatusError when raise_for_status=True. Transport failures raise lumen.TransportError. lumen.HTTPError still exists as a deprecated alias of StatusError.

Connection pooling is enabled by default and shared per client.

All public functions are thread-safe unless documented otherwise.

Responses are read lazily; call .read() to load the whole body.
