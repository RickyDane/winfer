Timeouts (lumen 3.x)

You are reading the docs for lumen 3.x (current).

Timeout.default() is 10 seconds total, with a 5 second connect timeout. Pass a number to set the total timeout.

Last updated for 3.0.0.

All public functions are thread-safe unless documented otherwise.
