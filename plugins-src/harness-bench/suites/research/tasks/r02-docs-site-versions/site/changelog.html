Changelog

Stable releases and pre-releases, newest first. Release notes are authoritative where reference pages lag behind.

3.5.0b1 — 2026-09-30 (pre-release)

  • Pre-release: the default total timeout will be raised to 20 seconds.
  • Pre-release: Python 3.10 support will be dropped (requires 3.11).
  • Proxy URLs may now include credentials.
  • Fixed redirect loop detection.

3.4.0 — 2026-07-02

  • Added Client.aclose().
  • Updated certifi pin.

3.3.1 — 2026-04-20

  • Proxy URLs may now include credentials.
  • Fixed redirect loop detection.
  • Fixed a leak of connections when a response is not closed.

3.3.0 — 2026-03-11

  • Dropped support for Python 3.9; lumen now requires Python 3.10 or newer.
  • Fixed iter_lines() splitting on CRLF.
  • Fixed redirect loop detection.

3.2.0 — 2025-12-01

  • The default total timeout of Timeout.default() (and therefore of lumen.Client) was raised from 10 to 15 seconds. The timeouts page has not been updated yet.
  • Improved type hints for Client.request.
  • Fixed a leak of connections when a response is not closed.

3.1.1 — 2025-09-14

  • Fixed redirect loop detection.
  • Added MockTransport helpers.
  • Fixed a leak of connections when a response is not closed.
  • Improved type hints for Client.request.

3.1.0 — 2025-08-02

  • RetryPolicy no longer retries POST even when max_attempts is set.
  • Fixed cookie domain matching for IP hosts.
  • Documentation fixes.

3.0.0 — 2025-05-05

  • New major version; see Upgrading.
  • Fixed cookie domain matching for IP hosts.
  • Fixed iter_lines() splitting on CRLF.
  • Added Response.elapsed.
  • Updated certifi pin.

2.9.3 — 2025-06-10

  • Security fix backported to 2.x.
  • Proxy URLs may now include credentials.
  • Added MockTransport helpers.
  • Fixed redirect loop detection.
  • Added Response.elapsed.

2.9.2 — 2025-02-01

  • HTTP/2 support is no longer experimental.
  • Fixed a leak of connections when a response is not closed.
  • Fixed iter_lines() splitting on CRLF.

2.9.0 — 2024-11-03

  • Added MockTransport helpers.

2.8.0 — 2024-06-21

  • Default retries raised from 3 to 5.
  • Fixed redirect loop detection.
  • Proxy URLs may now include credentials.
  • Updated certifi pin.
  • Added MockTransport helpers.

2.7.0 — 2024-01-15

  • Faster header parsing.

2.6.0 — 2023-09-09

  • Fixed iter_lines() splitting on CRLF.
  • Faster header parsing.

2.5.0 — 2023-04-12

  • Updated certifi pin.
  • Improved type hints for Client.request.
  • Added MockTransport helpers.
  • Faster header parsing.

2.0.0 — 2022-08-30

  • New major version.
  • Added Response.elapsed.
  • Added MockTransport helpers.
