Rate limits

Every endpoint belongs to a rate-limit tier, shown on its reference page. Base limits, in requests per minute (rpm), for the Pro plan:

TierBase rpm
light600
standard120
heavy20
bulk5

On other plans, a limit is the base limit times the plan multiplier (see Plans), rounded down. Add-ons (see Add-ons) are applied after the plan multiplier. Plan caps are applied last.

Limits are counted per endpoint (method + path) per account.
